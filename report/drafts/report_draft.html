0 Abstract

This report presents the design and implementation of a flood-risk digital twin for the SNCF Ligne 400 (Cévenol Corridor), a ~400 km railway line in southern France subject to extreme Mediterranean flash-flood events. The system integrates BIM infrastructure models, LiDAR-derived DTM terrain data, synthetic hydrological forecasting, and real-time decision support through a Streamlit dashboard.

The demonstrator monitors 120+ railway assets across 7 types (track segments, culverts, bridges, ditches, embankments), computing per-asset Water Surface Elevation against three-tier CAP-standard alert thresholds (Yellow/Orange/Red) over a 48-hour Cévenol storm scenario. A stitched cross-section viewer provides engineers with visual hydraulic context for each asset.

Keywords: Digital Twin, Railway Flood Risk, GIS, BIM, HEC-RAS, Streamlit, DTM, SNCF

1 Introduction & Problem Statement

1.1 Context

Railway infrastructure is increasingly vulnerable to climate-driven flooding. The Cévenol corridor (Ligne 400) traverses mountainous terrain in the Cévennes region of France, where extreme rainfall events — sometimes exceeding 40 mm/h sustained over several hours — create flash-flood conditions that threaten track integrity, drainage systems, and embankment stability.

1.2 Objective

Design and implement a digital twin demonstrator that can:

  1. Ingest terrain, infrastructure, and rainfall data into a unified geospatial model
  2. Simulate 48-hour flood forecasts with per-asset risk evaluation
  3. Produce operational alerts following CAP international standards
  4. Provide visual decision support through interactive maps and cross-sections

1.3 Scope

The demonstrator covers the Ligne 400 corridor with 103 base assets (expanded to 120+ after track segmentation). It uses synthetic WSE simulation in demo mode, with the architecture ready for HEC-RAS 6.7 integration when the hydraulic project file becomes available.

2 Literature Review

2.1 Digital Twins for Railway Infrastructure

Railway-specific digital twin work for SNCF and other infrastructure managers applies a layered structure tailored to rail assets, environmental context, and operational decision-making (IAHR, 2024). The recommended architecture follows a four-layer model: Physical System, Data/Integration, Analytics/Simulation, and Applications.

2.2 BIM–GIS Integration for Flood Risk

Research on BIM–GIS integration for disaster management highlights that BIM offers component-level information while GIS provides spatial context and terrain relationships. In flood-risk applications, BIM helps assess how individual components fail or incur damage, while GIS and DTM provide flood hazard and exposure information (El Mekawy et al., 2025; Vilgertshofer, 2017).

2.3 Hydrological Modelling Approaches

Flood-risk digital twin systems use a spectrum from threshold-based rules to hybrid physics/ML approaches. For a student MVP with limited calibration data, rule/threshold-based logic on top of static flood maps and DTM is recommended as the starting point (Fathom/Network Rail, 2024).

5 Hydrological Model

5.1 SWI Recursive Exponential Filter

The Soil Water Index quantifies soil saturation using a recursive exponential filter with a 10-day half-life:

SWI(t) = R(t) × (1 − C) + SWI(t−1) × C   where   C = 0.51/T, T = 240h

5.2 Sigmoid Runoff Coefficient

The runoff coefficient transitions smoothly between dry and saturated soil conditions:

Crunoff = Cmax / (1 + e−k × (SWI − SWImid))
ParameterValueMeaning
Cmax0.9Max runoff (90% of rain becomes surface flow)
Cmin0.1Min runoff (soil absorbs 90%)
k0.05Sigmoid steepness
SWImid150 mmSaturation midpoint

5.3 Synthetic Flood Polygons

Time-varying flood extents are generated by buffering the track and low-lying asset geometries proportionally to WSE intensity (5m–120m buffer range, quadratic scaling). Output: 48 GeoJSON FeatureCollections in EPSG:4326.

8 Results & Validation

8.1 System Performance

The demonstrator successfully processes a 48-hour Cévenol flash-flood scenario (peak 40.9 mm/h at T+15h) and generates per-asset risk assessments in real-time through the Streamlit dashboard. Key achievements:

  • All 120+ assets receive continuous WSE-based risk evaluation across 48 timesteps
  • CAP-colored map dots update in real-time as the timeline is scrubbed
  • Cross-section viewer correctly shows water level rise against terrain profile
  • Hotspot auto-focus correctly identifies the highest-risk asset per timestep
  • Alert hierarchy follows correct physics: low-lying drainage assets flood before track

8.2 Known Limitations

  • WSE simulation uses synthetic Rational Method — not calibrated HEC-RAS 2D physics
  • Flood polygons use corridor buffer approximation — not DTM-based bathtub model
  • 3D MULTIPATCH vertical datum not yet verified against DTM NGF
  • nearest_voie references in z_config still point to deleted Voie_0
  • No real-time MeteoFrance API integration (awaiting API key)

9 Conclusion & Future Work

9.1 Contributions

This project demonstrates that a functional flood-risk digital twin for railway infrastructure can be built using open-source tools (Python, Streamlit, GeoPandas, Rasterio) with a modular architecture that separates data ingestion, hydrological modelling, risk evaluation, and visualization. The system is ready for HEC-RAS integration when hydraulic project files become available.
